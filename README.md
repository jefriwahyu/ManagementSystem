DEMO

1. Login

![image](https://github.com/user-attachments/assets/2d3113bf-5f51-4fd9-a2f2-43b47f8cc9bb)

Halaman login dengan memasukan akun login username dan password nya admin.
   
3. Home

![image](https://github.com/user-attachments/assets/0dd5d1c3-2723-41b7-af50-e268ea474d20)

Halaman Home yang menampilkan 4 menu widget yaitu Dashboard, Menambah Data, Mengupdate Data, dan Logout. Pada bagian bawah terdapat nama dan NPM saya.
   
5. Dashboard

![image](https://github.com/user-attachments/assets/adde53be-e2ec-4c10-b8c4-d561479fd5e7)

Halaman dashboard yang menampilkan data penjualan dari No Faktur, Tanggal, Customer, Jumlah Barang, dan Total Penjualan. Pada bagian bawah terdapat button untuk kembali ke halaman home.
   
7. Add

![image](https://github.com/user-attachments/assets/b970ee43-ab5c-4d91-86fa-b5ec7a79bc78)

Halaman Tambah Data Penjualan untuk menambah data penjualan baru dengan mengiput form No Faktur Penjualan, Tanggal Penjualan, Nama Customer, Jumlah Barang, dan Total Penjualan. Klik Simpan Data untuk menyimpan data baru. Pada bagian bawah button Simpan Data terdapat button Kembali ke Home untuk kembali ke halaman home.
   
9. Update

![image](https://github.com/user-attachments/assets/03cdfcc0-894d-455e-b3b9-65856798ede2)

Halaman Update Data Penjualan untuk mengubah atau mengupdate data penjualan yang mungkin salah menginput, dengan menginputkan form Memilih No Faktur setelah itu form akan terisikan data sesuai dengan no faktur yang dipilih, setelah itu user dapat mengubah data yang diharuskan untuk diubah. Dari form Tanggal Penjualan, Nama Customer, Jumlah Barang, dan Total Penjualan. Klik Update data untuk mengupdate data. Jika selesai mengupdate data klik Kembali ke Home untuk kembali ke halaman home.
